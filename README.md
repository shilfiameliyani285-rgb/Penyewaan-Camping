### Deskripsi Singkat Program
Program ini merupakan aplikasi berbasis console (CLI) yang dibuat menggunakan bahasa pemrograman C untuk mengotomatisasi pencatatan transaksi pada usaha Adventure Camp. Program dapat menampilkan alat, menghitung biaya dan diskon sewa otomatis, serta melacak riwayat pendapatan.
